# backend: правила для агента

Java 21, Spring Boot 3, PostgreSQL. Подробности — в `docs/`.

## Слои
- `api` (контроллеры) → `service` → `repository`. Контроллер не ходит в репозиторий.
- DTO API — только в `api`, генерируются из `api/openapi/*.yaml`; в сервисы уходят доменные объекты.

## Ошибки
- Бизнес-ошибка — наследник `DomainException` с кодом из контракта; HTTP-статус задаёт
  `ApiExceptionHandler`, контроллеры статусы не выбирают.
- Тексты сообщений — `messages_ru.properties`, ключ = код ошибки.

## Данные
- Схема меняется только миграцией Flyway (`db/migration/V<n>__*.sql`), обратно совместимой
  с предыдущей версией сервиса.
- Транзакция — на методе сервиса, не в контроллере и не в репозитории.

## Тесты
- Сервисы — юнит-тесты; репозитории и API — Testcontainers PostgreSQL.
- Имя теста содержит `<capability>/<scenario>` из `covers:` задачи.
