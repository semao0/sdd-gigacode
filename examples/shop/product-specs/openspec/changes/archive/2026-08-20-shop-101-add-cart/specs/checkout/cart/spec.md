# Spec Delta

## Purpose
Корзина покупателя: добавление и удаление товаров, изменение количества и расчёт итоговой суммы заказа.

## ADDED Requirements

### Requirement: Добавление товара в корзину
Покупатель SHALL иметь возможность добавить в корзину товар, который есть в наличии.

#### Scenario: Товар в наличии
- **WHEN** покупатель добавляет в корзину товар, который есть в наличии
- **THEN** товар появляется в корзине с количеством 1
- **AND** итоговая сумма корзины пересчитывается

#### Scenario: Товара нет в наличии
- **WHEN** покупатель пытается добавить товар, остаток которого равен нулю
- **THEN** товар не добавляется
- **AND** покупатель видит сообщение «Товар закончился»

### Requirement: Расчёт итоговой суммы
Итоговая сумма корзины SHALL равняться сумме произведений цены на количество по всем позициям.

#### Scenario: Итог без скидки
- **WHEN** в корзине две позиции: 2 шт. по 500 ₽ и 1 шт. по 300 ₽
- **THEN** итоговая сумма равна 1300 ₽

#### Scenario: Пустая корзина
- **WHEN** в корзине нет товаров
- **THEN** итоговая сумма равна 0 ₽
- **AND** оформление заказа недоступно
