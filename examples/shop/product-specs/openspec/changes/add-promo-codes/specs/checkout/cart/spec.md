# Spec Delta

## MODIFIED Requirements

### Requirement: Расчёт итоговой суммы
Итоговая сумма корзины SHALL равняться сумме произведений цены на количество по всем позициям
за вычетом скидки по применённому промокоду. Итоговая сумма MUST NOT быть меньше 0 ₽.

#### Scenario: Итог без скидки
- **WHEN** в корзине две позиции: 2 шт. по 500 ₽ и 1 шт. по 300 ₽
- **THEN** итоговая сумма равна 1300 ₽

#### Scenario: Пустая корзина
- **WHEN** в корзине нет товаров
- **THEN** итоговая сумма равна 0 ₽
- **AND** оформление заказа недоступно

#### Scenario: Итог со скидкой промокода
- **WHEN** сумма позиций 1300 ₽ и применён промокод на фиксированную скидку 500 ₽
- **THEN** итоговая сумма равна 800 ₽

#### Scenario: Скидка больше суммы корзины
- **WHEN** сумма позиций 300 ₽ и применён промокод на фиксированную скидку 500 ₽
- **THEN** итоговая сумма равна 0 ₽
