# Spec Delta

## Purpose
Промокоды в корзине: покупатель получает скидку по коду акции с учётом срока действия, минимальной суммы и лимита использований.

## ADDED Requirements

### Requirement: Применение промокода
Покупатель SHALL иметь возможность применить к корзине действующий промокод и получить скидку.
Код вводится без учёта регистра и пробелов по краям.

#### Scenario: Успешное применение
- **WHEN** покупатель вводит действующий промокод `AUTUMN10` на скидку 10% при сумме корзины 2000 ₽
- **THEN** промокод применяется
- **AND** покупатель видит скидку 200 ₽ и итог 1800 ₽

#### Scenario: Неизвестный промокод
- **WHEN** покупатель вводит код, которого не существует
- **THEN** промокод не применяется
- **AND** покупатель видит сообщение «Промокод не найден»

#### Scenario: Истёкший промокод
- **WHEN** покупатель вводит промокод, срок действия которого закончился
- **THEN** промокод не применяется
- **AND** покупатель видит сообщение «Срок действия промокода истёк»

#### Scenario: Не выполнена минимальная сумма
- **WHEN** покупатель вводит промокод с минимальной суммой 3000 ₽ при сумме корзины 2000 ₽
- **THEN** промокод не применяется
- **AND** покупатель видит, сколько не хватает до минимальной суммы: «Добавьте товаров ещё на 1000 ₽»

### Requirement: Один промокод на заказ
К корзине SHALL быть применён не более чем один промокод.

#### Scenario: Замена промокода
- **WHEN** к корзине применён промокод и покупатель применяет другой действующий промокод
- **THEN** действует только новый промокод
- **AND** скидка пересчитывается по новому промокоду

#### Scenario: Удаление промокода
- **WHEN** покупатель удаляет применённый промокод
- **THEN** скидка убирается и итог пересчитывается без скидки

### Requirement: Лимит использований
Промокод SHALL перестать применяться, когда исчерпан его лимит использований. Использованием
считается оформленный заказ, а не применение в корзине.

#### Scenario: Лимит использований исчерпан
- **WHEN** покупатель вводит промокод, по которому уже оформлено максимальное число заказов
- **THEN** промокод не применяется
- **AND** покупатель видит сообщение «Промокод больше не действует»
