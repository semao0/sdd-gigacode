## Скил `sdd-qa-testcases`: тест-кейсы в Jira по сценариям спек

QA запускает скил в store после DoR. Скил создаёт в Jira тест-кейс на каждый сценарий change
(бизнес-спеки и `integration/`), связывает его с историей и ставит ID `<capability>/<scenario>`.
Шаги берёт из WHEN/THEN. При повторном запуске обновляет изменённые кейсы, а для удалённых
сценариев помечает их устаревшими, без дублей. Правило — в
[02-process.md](docs/02-process.md#правила-работы).

**Сначала выяснить у QA**, где хранятся кейсы. От этого зависит интеграция:

| Где кейсы | Как |
|---|---|
| Обычный тип задачи | Atlassian MCP |
| Xray (тип Test с панелью шагов) | Atlassian MCP + шаги в описании или API Xray |
| Zephyr Scale (ключи `SHOP-T123`) | REST API Zephyr с токеном |

**Готово, когда** на тестовом проекте Jira кейсы создаются, повторный запуск не плодит дублей,
а метрика 4 учитывает ручные кейсы.
